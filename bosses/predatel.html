Предатель

Босс локации «Центр Кастовска»

Атака 190
Защита 139 + 100

Как найти

Предатель находится в локации «Центр Кастовска». Чтобы найти его, положите в рюкзак исполнителя «Охотничий нож». Навык «Охота» увеличит шанс нахождения босса вдвое.

Условия боя

⚠ На босса иди в самом лучшем снаряжении — это пошаговый бой на выживание. Атака и защита выше — это минимум по рекомендованному набору локации, для боя с боссом бери максимум.

На локации вас будет ожидать босс и пошаговое сражение с ним. Для увеличения шансов на выживание используйте свое лучшее снаряжение. Вы также можете положить в рюкзак предмет «Дымовая граната» — это позволит в любой момент остановить сражение.

Добыча с босса

Эвакуатор Легендарное Специальная версия автомобиля "Кастовия 102", переоборудованная для эвакуации легковых и грузовых автомобилей. Уникальная конструкция предмета не позволит его отремонтировать. Чтобы привезти этот транспорт, нужно отправляться в рейд на эвакуаторе.
Заметки лесника Мистическое Уникальная книга лесника, в которой описан его опыт выживания в секторе. С помощью нее можно разблокировать локацию в одноименном разделе во внутриигровом смартфоне. Там можно узнать где найти какой-либо предмет, а также увидеть рекомендуемое снаряжение.
Отвертка Легендарное Незаменимая вещь. Есть в каждом доме. В секторе тоже, наверняка, пригодится.
Куртка предателя Мистическое Защита: 70 Легкая броня из твердой кожи с усиливающими пластинами. Защиту компенсируют мобильность и комфорт. Уникальная конструкция предмета не позволит его отремонтировать.
СМУЗИ-404 Мистическое Урон: 205 Пистолет-пулемет Австрийской марки SMUZI. Отличается высокой скорострельностью, простотой и надежностью. Уникальная конструкция предмета не позволит его отремонтировать.
Маленький ящик с материалами Мистическое Контейнер с материалами для ремонта. Можно разобрать в лагере и переработать в 2500 материалов. Предмет тяжелый, для его получения необходимо отправляться в рейд на автомобиле.
Дневник сталкера. Том третий. Легендарное Третья часть дневника, в котором собран опыт неизвестного сталкера о выживании в закрытом секторе. Повышает опыт исполнителя на 1000 единиц. Можно использовать на исполнителях со званием "Командир сержантского звена" и ниже.
Командирские часы Мистическое Трофейные часы, снятые с противника.
Шапка предателя Мистическое Защита: 4 Самая обычная шапка. Уникальная конструкция предмета не позволит его отремонтировать.
Пластина Редкое Пластина для бронежилетов. Можно переработать в лагере для получения материалов для ремонта через верстак для разборки.
Коробка с материалами Редкое Контейнер с материалами для ремонта. Можно разобрать в лагере и переработать в 1000 материалов.
Чертеж верстака для разборки Редкое Чертеж верстака для разборки, который позволит построить этот верстак в лагере.
Болты и гайки Обычное Стандартный набор для ремонта техники различной сложности.
